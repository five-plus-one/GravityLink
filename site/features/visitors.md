# 访客记录

查看每一次访问的明细：时间、链接、IP 解析地域、设备、系统/浏览器、来源。

![访客记录](https://img.assets.five-plus-one.com/img/2026/09/bd3649e1537d9ec7a7efeec09e587581.png)

## 能查什么

| 维度 | 说明 |
|------|------|
| 链接 | 全部或指定短码 |
| 时间 | 开始/结束（RFC3339 或快捷范围） |
| 关键词 | IP、短码、名称 |
| 分页 | 按时间倒序，稳定分页 |

快捷范围：今天、最近 24 小时、近 7 天、近 30 天。查询条件在翻页时保持。

## 字段含义

- **时间**：服务器本地时区  
- **地域**：ip2region 解析；内网/保留地址会显示为「内网或保留地址」  
- **设备**：mobile / tablet / desktop / bot / unknown  
- **系统/浏览器**：UA 关键词匹配；微信内会识别 MicroMessenger  
- **来源**：Referer；直接打开显示「直接访问」  

## 和统计图的关系

- 统计图是聚合；访客记录是原始明细  
- 今日明细依赖异步消费，通常数秒后可见  
- 保留期内查询 + 归档表联合；超过 90 天可能只剩归档  
- 旧数据缺 UA/地域不会「脑补」补造  

## 时间范围规则

- 区间左闭右开  
- 跨度过长或非法区间会返回明确错误  
- 「最近 24 小时」是滚动窗口  

## 使用场景

- 投放异常：看 IP 与 UA 是否被刷  
- 转化排查：确认目标渠道码是否真的进量  
- 客诉：核对某用户访问时间与跳转结果  

## 性能与清理

明细写在 `access_logs`，约 90 天后归档。查询走索引与分页，不要无限制拉全表。

工程规格：仓库 `Docs/features/statistics.md`。
