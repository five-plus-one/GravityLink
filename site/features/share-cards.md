# 微信分享卡片

控制链接在微信内分享时的标题、描述与封面，让转发不像「裸链」。

![微信分享卡片](https://img.assets.five-plus-one.com/img/2026/09/99347fd8f9e6a8ebcfea4727204a4e03.png)

## 需要什么前提

1. 已认证服务号 / 公众号（具备 JS-SDK 权限）  
2. 公众号后台配置 JS 接口安全域名  
3. 服务器 IP 加入公众号白名单  
4. 在 GravityLink「系统设置」里填写 AppID / AppSecret 并保存  

AppSecret 服务端加密存储，查询接口只返回是否已配置，不回传明文。

## 卡片内容

| 字段 | 说明 |
|------|------|
| 标题 | 微信卡片主标题 |
| 描述 | 副文案 |
| 封面 | 从素材库选择或上传 |
| 关联链接 | 绑定到某条短链/落地页 |
| 启用状态 | 停用后公开分享走默认行为 |

## 签名如何工作

1. 用户打开你的公开页（入口域名）  
2. 页面向服务端要 JS-SDK 签名  
3. 服务端用当前 URL（不含 hash）与 jsapi_ticket 签名  
4. 前端调用 `wx.config` 后即可自定义分享  

票据在内存缓存，过期自动刷新；保存配置会使票据失效。

## 配置检测

保存公众号配置后，管理端可点「检测」：

- 成功：说明服务端能取到 JS-SDK 票据  
- **不代表**：安全域名、手机实际分享、IP 白名单已全部验收  

失败时只返回阶段名与微信错误码，不回传密钥或上游正文。

## 常见问题

| 现象 | 排查 |
|------|------|
| 分享无卡片标题 | 是否调用成功 `wx.config`；URL 是否与安全域名一致 |
| 签名 invalid | 公众号配置错误；页面 URL 带了 hash；票据过期 |
| 检测成功但手机不行 | 安全域名未备案/未配；IP 白名单；从非微信内打开 |
| 封面不显示 | 图片 URL 是否公网可访问 |

## 实践建议

- 封面用正方形或 5:4，避免关键信息贴边  
- 标题控制在一行内更清晰  
- 换域名后重新配置安全域名并回归测试分享
