# 短链接

把长 URL 映射到可分享的短码。访问 `/{code}` 时 302 跳转，或先展示落地页再跳。

## 短码规则

| 方式 | 规则 |
|------|------|
| 自定义 | 字符 `[a-zA-Z0-9_-]`，长度 2–32；匹配不区分大小写，存储保留你写的大小写 |
| 自动生成 | 数据库自增 ID → Base62（`0-9a-zA-Z`），ID 越大短码自然变长 |
| 唯一性 | **全局唯一**（跨短链/渠道码/群活码共用）；冲突返回错误 4001 |
| 回收 | 删除或软删**都不回收短码**，避免旧链接被新内容劫持 |

目标 URL 必须是合法的 `http://` 或 `https://` 地址。

## 跳转逻辑

```text
访问 /{code}
  → 校验状态（active 且未过期）
  → 若配置了中转域名：先 302 → {transit}/{code}
  → 若挂了落地页：302 → {landing}/{code}
  → 否则：302 → target_url
```

| 访问结果 | HTTP | 用户看到什么 |
|----------|------|----------------|
| 正常 | 302 | 目标站或落地页 |
| 已禁用 | 404 | 系统 404 |
| 已过期 | 410 | 系统过期提示页 |
| 未知短码 / 域名未登记 | 404 | 系统 404 |

## 过期与状态

- `expire_at` 为空：永不过期  
- 到期后由缓存层判定，立刻不再跳转  
- 状态流转：`active ↔ disabled`（手动）；`active → expired`（到期自动）

## 管理端怎么用

### 创建

1. **短链接** → 新建，类型选「短链接」  
2. 填**目标 URL**（必填）  
3. 可选：自定义短码、标题/备注、过期时间  
4. 可选：选择**入口域名**（决定最终分享出来的地址前缀）  
5. 可选：关联**落地页**、**中转域名**  
6. 保存后列表会展示完整公开地址，可复制或生成二维码

### 列表与详情

- 筛选：状态、类型、时间、关键词（短码/标题）  
- 详情页：链接信息 + 统计快览（PV/UV 趋势）  
- 批量：多选后批量禁用 / 启用 / 删除；也可转移分类、增删标签  

![链接管理列表](https://img.assets.five-plus-one.com/img/2026/09/490a54d7e8ec41449bd8d0fce35a1b95.png)

列表中可直接看到类型、公开地址、访问量与状态；右侧操作含打开地址、二维码、统计、编辑与禁用。

点击「创建链接」后可选类型并填写字段：

![创建链接弹窗](https://img.assets.five-plus-one.com/img/2026/09/9d9ab670c80b4edc3db4b7342f1cf341.png)

常见字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 类型 | 是 | 短链接 / 渠道链接 / 活码 |
| 分类与标签 | 否 | 便于筛选与批量操作 |
| 名称 | 否 | 仅管理端识别 |
| 短码 | 否 | 留空自动生成 |
| 入口域名 | 是 | 决定公开地址前缀 |
| 目标 URL | 是 | 跳转目的地 |
| 访问限制 | 否 | 如口令/频率等 |
| 过期时间 | 否 | 到期后 410 |

### 地址与二维码

- 复制的地址按该链接绑定的**入口域名**拼接，不会误用列表里第一个域名  
- 入口域名停用或未配置时，复制/打开会禁用并提示原因  
- 二维码在浏览器本地生成，图片即完整公开 URL；手机扫码需要域名已解析到公网  

::: warning 验收提醒
本机 `localhost` 生成的二维码只适合本机测试。手机扫不通时，先检查 DNS 和 Nginx，而不是短码本身。
:::

## 常见问题

| 现象 | 排查 |
|------|------|
| 点开 404 | 域名是否在后台添加且 active；Nginx 是否转发到短链端口（不是后台端口） |
| 点开 410 | 链接已过期，在后台改过期时间或重建 |
| 点开 404 但域名没问题 | 链接是否被禁用；短码是否写对（不区分大小写） |
| 手机打不开 | DNS 未生效 / 证书错误 / 防火墙未放行 |
