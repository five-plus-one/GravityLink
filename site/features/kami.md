# 卡密分发

把激活码、兑换码批量导入项目，访客打开领取页自助提取，支持口令与防重复规则。

![卡密分发](https://img.assets.five-plus-one.com/img/2026/09/f8b8398cd9240b6c8de276db2066a193.png)

## 核心概念

| 概念 | 说明 |
|------|------|
| 卡密项目 | 一组卡密的容器，绑定领取页与规则 |
| 库存 | 已导入未领取的卡密数量 |
| 提取记录 | 谁在何时领了哪条 |
| 口令 | 领取前需输入的项目口令（可保留/修改/取消） |
| 领取页 | 落地页 `kami` 模板 + 活码链接 |

## 典型流程

1. **卡密分发** → 新建项目  
2. 导入卡密（按项目去重；重复项跳过）  
3. 配置口令、是否允许同一访客重复领取等  
4. 生成领取页（选入口域 + 落地域）→ 得到短链/二维码  
5. 分发链接；访客打开 → 输口令 → 领取  
6. 后台看库存与提取记录  

## 口令与并发

- 口令保存后**下次领取立即生效**  
- 同一项目并发领取会走事务 + 去重规则，避免超发  
- 访客识别默认按 IP；共出口 IP 的用户可能受同一规则约束  

## 与落地页/活码的关系

- 领取页使用 `kami` 模板，内容里绑定 `project_id`  
- kami 活码**不需要**配二维码目标  
- 公开页领取成功后会保留本次卡密，便于复制  

## 运营清单

- 大促前先导入并小号自测一条  
- 库存见底及时补货，避免落地页点领取失败  
- 口令不要写进公开文案，应线下或单独渠道告知  
- 提取记录可导出对账（若管理端提供导出；否则列表筛查）
