# 素材库

集中存放二维码、Logo、封面等图片。群活码目标、分享卡片、落地页都可以从这里选图，避免反复上传同一张图。

![素材库列表](https://img.assets.five-plus-one.com/img/2026/09/c8a48ab04ba26e6625ce49b3f7b12467.png)

## 能做什么

| 操作 | 说明 |
|------|------|
| 上传图片 | PNG / JPG / GIF / WebP，单张 ≤ 5MB |
| 预览 | 列表直接看缩略图 |
| 重命名 | 改显示名，不影响存储路径 |
| 复制图片链接 | 得到可外链地址（本地 `/uploads/...` 或 OSS URL） |
| 删除 | 本地或云端（若配置了对象存储） |
| 筛选 | 按名称、存储位置 |

## 存储位置

- **本地**：写在应用数据卷 `/data/uploads`，通过同源 `/uploads/{name}` 访问  
- **对象存储**：在系统设置里配置 S3 兼容 / 阿里云 OSS 等后，上传走云存储，链接可能是 CDN 域名  

管理端只返回「是否已配置」和脱敏信息，不回传密钥。

## 和群活码的关系

活码目标里的二维码 URL 建议：

1. 先上传到素材库  
2. 选图后系统保存为同源 `/uploads/...`  
3. 公开落地页随当前访问域名加载，**不要**写死 `localhost`

历史 loopback 地址在渲染时会兼容转换。

## 实践建议

- 文件名用业务语义（如 `group-a-2026.png`），便于检索  
- 换群码时：传新图 → 改目标 URL → 需要时重置扫码计数  
- 定期清理未引用素材，节省卷或 OSS 空间  

## 安全

- 管理接口需登录，且素材管理通常仅管理员可见  
- 自定义 HTML 落地页引用素材时仍会做 sanitize，不能借图床注入脚本  
- 对象存储 AK/SK 加密保存，查询接口脱敏  

工程规格：仓库 `Docs/features/object-storage.md`。
