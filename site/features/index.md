# 功能总览

GravityLink 围绕「一次访问如何被路由」组织能力。所有业务共用同一入口域名和短码体系，区别只在跳转前多做什么（拼渠道参数、轮换二维码、展示落地页）。

## 一张图看懂链路

```text
用户点击 / 扫码
        │
        ▼
  入口域名 /{code}          例：go.example.com/abc123
        │
        ├─ 配置了中转？ ──► 中转域名 /{code}（再记一层统计，隔离入口）
        │
        ├─ 有落地页？  ──► 落地域名渲染页面（群码 / 提示 / 客服 / 卡密）
        │
        └─ 都没有？    ──► 302 直达目标 URL
        │
        ▼
  异步写入统计（PV / UV / 设备 / 地域 / 明细）
```

## 核心模块

| 模块 | 解决什么问题 | 典型场景 |
|------|--------------|----------|
| [短链接](./short-link) | 长 URL 难分享、难管理 | 线下物料、短信、口头传播 |
| [渠道码](./channel-code) | 分不清流量来自哪 | 多平台投放、AB 素材对比 |
| [群活码](./live-qr) | 群满/码废要换印 | 微信群长期拉新、线下海报 |
| [落地页](./landing-page) | 跳转前需要承接 | 扫码页、跳转提示、客服、卡密 |
| [统计分析](./statistics) | 不知道效果 | 看 PV/UV、地域、时段、设备 |

域名路由细节见[域名管理](/guide/domains)。

## 你可以先做什么

1. 按[快速开始](/guide/quick-start)完成部署与初始化  
2. 添加[入口域名](/guide/domains)（必须 active 才能命中短链）  
3. 建第一条短链，用手机点一次  
4. 打开统计，确认有访问记录  

## 管理端全局能力

除业务模块外，后台还提供：

- **列表与批量**：按状态/类型/时间/关键词筛选；多选后批量启停、改分类、标签增删替换
- **分类与标签**：独立目录管理，支持重命名、合并转移；删除分类后链接归「未分类」
- **入口二维码**：短链 / 群活码 / 分享卡片可本地生成 PNG 二维码，不请求第三方
- **素材库**：二维码与图片可上传、选择、删除；支持对象存储（OSS/CDN）或本地存储

## 权限边界

- 短链端口（默认 `18080`）只服务公网访问与落地页渲染，**不**暴露管理写接口  
- 管理后台（默认 `18081`）负责登录、CRUD、初始化；生产环境建议仅内网或 HTTPS + 白名单  
- 业务数据在你的 MySQL；配置与上传文件在 Docker 卷 `/data`
