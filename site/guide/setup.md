# 初始化向导

首次打开管理后台、且系统未完成安装时，会进入初始化。公网短链端口**不提供**初始化写接口。

## 状态机（你只需要知道结果）

1. 读环境变量与 `CONFIG_FILE`  
2. 配置完整且 MySQL/Redis 可用 → 直接进业务  
3. 否则后台进入初始化态；短链端口提示未初始化  
4. 你完成三步后：写配置文件、建表、锁定初始化接口  

## 第一步：连接数据服务

### MySQL

| 字段 | 说明 |
|------|------|
| Host / Port | 数据库地址，默认 3306 |
| Database | 库名；不存在会尝试创建 |
| User / Password | 需要有建表权限 |
| 连接参数 | 推荐 `charset=utf8mb4&parseTime=True&loc=Local` |

### Redis

| 字段 | 说明 |
|------|------|
| Host / Port | 默认 6379 |
| DB | 通常 0 |
| Password | 无密码留空 |

**必须点「测试连接」成功**才能下一步；通过后连接信息会保存到配置文件。

### 预填默认值

Compose 里的 `SETUP_DEFAULT_MYSQL_HOST` / `SETUP_DEFAULT_REDIS_HOST` 只是向导第一次展示的默认 Host，不是强制配置。

## 第二步：管理员身份

### 方式 A：本地账号（多数自托管）

- 用户名 ≥ 3 位  
- 密码 ≥ 10 位  
- 密码只存强哈希，不回传、不打日志  

初始化完成后，打开 `http://服务器IP:18081/login` 用该账号登录：

![管理员登录页](https://img.assets.five-plus-one.com/img/2026/09/e1bcbc0699e80cadcd80049da7e69b22.png)

### 方式 B：Logto OIDC

填 Issuer、App ID、Audience 等，完成一次真实登录验证。

回调地址：

```text
{管理端公开地址}/setup/auth/callback
```

Logto 角色声明**不会**直接当作后台授权依据，以后台本地角色为准。

## 第三步：确认并启用

1. 核对数据库与管理员信息  
2. 填**公开访问地址**：用户最终打开短链的地址  
   - 例：`https://s.yourdomain.com`  
   - 或临时：`http://服务器IP:18080`  
3. 点「完成初始化」  

系统会：建空表（或受控迁移）、启用业务路由、锁定初始化接口、进入后台。

登录后的**系统设置**可维护站点参数、认证方式等：

![系统设置](https://img.assets.five-plus-one.com/img/2026/09/c788bbeb7c5e74bcca1acd1bd205faf3.png)

之后若换了公开域名，到设置里改，避免落地页/分享卡片拼错前缀。

## 配置优先级

1. 非空环境变量  
2. `CONFIG_FILE`（默认 `/data/gravitylink.json`）  
3. 开发默认值  

空环境变量不会覆盖已保存配置。配置文件含数据库密码，权限应仅运行用户可读写。

## 重置初始化

仅超级管理员可在设置执行「清除所有配置」：

- 需要重新认证 + 确认短语  
- 会清系统配置与安装状态，并禁用旧账号  
- **短链、域名、落地页、统计数据默认保留**  
- 重置期间有 reset marker，进程崩溃也能正确回到初始化态  

## 安全边界

- `/api/setup/*` 只在管理端监听器  
- 初始化完成后测试/保存接口返回锁定  
- production 无「无认证管理模式」  
- API 状态响应不含数据库/Redis 密码  
- 初始化接口应限制在可信网络；完成后仍建议限制后台公网暴露  

## 验收时常见坑

- MySQL 远程未授权 → 测试连接失败  
- 用短链端口去填公开地址 → 落地页/分享前缀错误  
- 初始化完没加入口域名 → 短链 404  
- 时区没设 → 日切和过期时间不对
