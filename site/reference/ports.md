# 端口与拓扑

## 容器端口

| 容器内 | 职责 |
|--------|------|
| `8080` | 短链跳转、落地页渲染、公开静态资源 |
| `8081` | 管理后台 SPA、管理 API、初始化向导 |

## 推荐宿主机映射

| 宿主机 | 容器 | 谁访问 |
|--------|------|--------|
| `18080` | `8080` | 仅 Nginx 回源（不要对公网裸奔） |
| `18081` | `8081` | 仅 Nginx 回源 + 白名单 |

若只开 443：宿主机 18080/18081 可绑 `127.0.0.1`：

```yaml
ports:
  - "127.0.0.1:18080:8080"
  - "127.0.0.1:18081:8081"
```

## 推荐拓扑

```text
Internet
   │ 443
   ▼
 Nginx
   ├─ s.example.com     → 127.0.0.1:18080   入口短链
   ├─ page.example.com  → 127.0.0.1:18080   落地页
   └─ admin.example.com → 127.0.0.1:18081   后台（allow 白名单）

 内网
   ├─ MySQL :3306
   └─ Redis :6379

 Docker
   └─ volume gravitylink_data → /data
```

## Compose 项目名

```yaml
name: gravitylink
```

固定项目名，避免不同工作目录启动出两套服务抢端口。

## 防火墙清单

| 端口 | 建议 |
|------|------|
| 22 | 按需，限来源 |
| 443 | 放行 |
| 18080/18081 | 不对 0.0.0.0/0 放行；只给本机 Nginx |
| 3306/6379 | 仅内网 |

## 与域名路由的对应

| 域名类型 | 反代到 |
|----------|--------|
| entry | 18080 |
| transit | 18080 |
| landing | 18080 |
| 管理 | 18081 |

全部必须 `proxy_set_header Host $host`。

## 健康检查建议

- 短链：固定测试码 `https://s.example.com/health-ping`（可指向落地页或已知 302）  
- 后台：`https://admin.example.com/` 返回 200 HTML  
- 依赖：MySQL/Redis 端口连通  

## 扩缩容说明

当前为单进程有状态（本地缓存 + 内存域名表）。多实例需要额外设计会话/缓存一致性；自托管场景通常单机足够。
