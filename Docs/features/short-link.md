# 功能规格：短链接

## 功能描述

将长 URL 映射到一个短码，通过短链接访问时 302 跳转到目标 URL，或先展示落地页再跳转。

## 短码生成规则

1. **自定义短码**：用户指定，字符范围 `[a-zA-Z0-9_-]`，长度 2–32 位，不区分大小写（统一存储为原始大小写，匹配时 case-insensitive）
2. **自动生成**：数据库自增 ID → Base62 编码，字符集 `[0-9a-zA-Z]`，最短 1 位，随 ID 增长自然增长
3. 短码全局唯一（跨所有链接类型），冲突时返回 4001 错误

## 跳转逻辑

```
访问 /{code}
  → 校验链接状态（active / 未过期）
  → 无落地页：302 → target_url
  → 有落地页：302 → {landing_domain}/{code}
  → 配置了中转：先 302 → {transit_domain}/{code}，再执行上述逻辑
```

## 过期机制

- `expire_at` 为 NULL：永不过期
- 过期后访问：返回 410 Gone，展示系统默认过期提示页
- 过期检测在 Redis 缓存层进行（缓存中存储 expire_at，Go 侧判断）

## 状态流转

```
active → disabled（手动禁用）
active → expired（过期时自动）
disabled → active（手动启用）
```

禁用状态访问：返回 404

## 管理端功能

- 创建短链接（填写 target_url、短码、过期时间、关联域名、可选落地页）
- 列表页：按状态、类型、时间过滤；支持搜索短码和标题
- 详情页：链接信息 + 统计图表快览
- 批量操作：批量禁用、批量删除

## 约束

- 同一短码不可被两条不同链接使用（即使其中一条已删除，短码也不回收，避免旧链接被劫持）
- `target_url` 必须是合法 HTTP/HTTPS URL
- 软删除不释放短码
