# 微信分享卡片与素材

2026-09-07 用户确认实施。管理端独立管理卡片：标题、摘要、图片 URL、目标 URL、入口域、启停。公开 `/card/:id` 页面展示卡片，配置微信 JS-SDK，用户通过按钮访问目标；禁止立即 302 导致分享配置丢失。

公众号配置只允许管理员维护。AppSecret 服务端 AES-GCM 加密，密钥保存在配置文件同目录的独立文件（0600），不通过查询接口返回。空密钥输入保留原值。票据和 access_token 内存缓存，过期重新获取；签名使用页面完整 URL（不含 hash）。外部请求设置超时，不向客户端返回上游凭据或错误正文。实际微信验收需公众号权限、IP 白名单、JS 接口安全域名。

素材仅接受 JPEG/PNG/GIF/WebP，最大 5 MiB，使用随机文件名存入配置目录的 uploads 子目录，公开只读；不接受 SVG/HTML。素材和卡片采用新增表迁移，旧数据不清除。

接口：管理员 `/api/admin/materials` 上传/列表；`/api/admin/share-cards` 列表/创建、`/:id` 更新；`/api/admin/wechat-config` 查询（脱敏）/保存。公开卡片严格检查启停和域名。

自动测试必须与真实微信客户端验收分开记录；未提供可用公众号时不得宣称已通过真实分享验证。

## 配置连接检测（2026-09-07）

管理员可在保存配置后调用 `POST /api/admin/wechat-config/check` 检查已保存配置能否取得 JS-SDK 票据。成功仅代表服务端票据可用，不代表安全域名、手机访问或客户端分享已经验收。失败仅返回固定阶段名和微信数字错误码，不回传上游错误正文、URL、密钥或票据。公开签名接口继续返回通用错误。检测复用有效票据，避免反复请求上游；保存配置使票据失效。弹窗保留保存结果并提供检测入口，编辑未保存时禁止检测，避免检测旧配置造成误解。
