# 上下文详情与素材删除

- 统计导航保留独立主页面。链接列表、概览最近链接、分享面板中的单条统计使用详情侧栏，展示时间选择、访问量、趋势和设备分布。关闭后原页面保持筛选、分页、勾选与滚动位置。
- 分享面板内打开统计后可关闭统计返回分享面板。素材选择器内管理素材使用嵌套侧栏，关闭后刷新素材列表并保留原表单。
- 模块导航及概览的“全部链接”等明确进入主模块的操作继续使用路由；外部访问地址继续打开新标签页。
- 素材每行提供复制图片链接和删除，支持批量复制与删除。删除包含存储文件与素材记录，确认中提示已引用页面可能无法显示图片。仅能删除本地文件或当前配置所属存储的对象；配置不匹配时明确提示，保留记录。批量逐项返回结果以支持失败重试。

## 验收
Go全量测试、前端23项测试及构建通过。已部署两个本地Docker应用。真实OSS删除、本地文件删除、素材记录移除、逐项失败返回、匿名访问拒绝均通过（scripts/e2e_material_delete.py）。浏览器验证筛选结果中的单条统计在原链接页侧栏展示，显示时段PV/UV及设备数据；关闭后筛选条件仍在。素材行内复制链接和删除入口可操作。
