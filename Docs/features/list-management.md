# 列表管理与卡密设置

## 交互方案
- 卡密项目卡片与详情页提供“项目设置”。口令支持保留、修改、取消；保存后下次领取立即使用新规则。
- 链接页将搜索、分类筛选、创建作为常用操作，其余筛选可展开。启用开关与操作列固定在右侧。
- 分类与标签可独立创建、重命名、多选删除或合并转移。删除分类后链接归入未分类，删除标签只解除关联；转移会保留链接。
- 支持多选链接、选择全部筛选结果，批量转移分类、追加/移除/替换标签及启停。
- 分类目录存于现有配置表，已有链接分类自动加入目录；批量变更在事务中执行，不新增数据库结构。
- 分页表格根据可用屏幕高度滚动内容，分页留在可见区域。顶栏缩为48像素，减少页面留白。

## 验收
验证口令修改与取消、目录持久保存、批量关联、合并与删除、失败回滚；运行前后端检查并部署本地Docker，检查桌面与手机分页位置。
