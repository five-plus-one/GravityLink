# 图片对象存储

图片库支持本地存储与 S3 兼容存储（含阿里云 OSS），管理员配置 Endpoint、Region、Bucket、路径前缀、访问密钥、CDN 域名及路径寻址方式。密钥加密保存，查询只返回已配置状态；常规系统配置接口不得读写存储配置。

新上传先写入对象存储，成功后登记素材并返回 CDN URL。批量迁移逐张上传本地素材，成功后更新素材 URL；旧 /uploads/ 地址按素材名称查找并跳转到 CDN，兼容已发布内容。失败保留本地素材，可重试；本地文件保留。单张迁移为独立请求，客户端展示进度并可重新打开继续。

验收采用本地 S3 服务验证签名、内容、CDN URL、配置脱敏、旧地址兼容和重复迁移；真实 OSS 凭据由管理员在设置页面填写。

S3兼容性参考：[阿里云 OSS S3 V4签名说明](https://www.alibabacloud.com/help/en/oss/user-guide/0002-00000429)。使用 MinIO Go SDK SigV4 上传。密钥加密文件使用数据目录 wechat.key，备份时与数据库一同保留。

迁移服务器时必须同时保留数据库与数据目录中的 wechat.key。若密钥文件丢失导致旧密文无法解密：查询存储状态返回空配置；保存与检测在表单已填写 Secret Access Key 时直接用新凭据覆盖写入，不再依赖旧密钥；Secret 为空则提示填写后重试。

## 上传检测与素材管理
- OSS Endpoint 自动规范为 S3 兼容地址，使用域名寻址并从 Endpoint 校验地域；关闭分块编码。
- 检测上传使用当前表单，保留已保存的密钥，分别检查图片写入与 CDN 读取；检测成功的图片可在素材库查看。
- 错误按地域、桶名、授权、网络分类显示，不回传密钥和签名原文。
- 素材库提供搜索、分页、预览、重命名、多选移出、上传和本地图片迁移。移出素材库保留已有访问地址。
- 素材移出标记保存在现有配置表，不新增数据结构。
