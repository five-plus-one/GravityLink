# 列表与素材管理验收

- 卡密项目支持保留、修改和取消提取口令，修改后旧口令被拒绝，新口令可领取；接口不返回口令。
- 分类与标签支持独立添加、多选删除、重命名与合并转移；链接支持批量分类、标签及启停。无效链接导致整批操作回滚。
- 桌面表格按屏幕高度限制内容区域，分页可见；链接启用与操作列固定。手机链接使用卡片和顶部分页。
- 素材库提供上传、预览、搜索、重命名、多选移出和本地图片迁移。移出后已有访问地址继续有效。
- 存储检测按当前表单验证写入与 CDN 读取，检测图片保存在素材库。

## OSS 实测
本地验收环境的存储设置已修正为上海地域与指定存储桶。系统使用 S3 兼容 Endpoint、域名寻址、普通请求体上传。真实图片已上传阿里云 OSS，并通过用户配置的 CDN 域名读取，内容一致。本地图片迁移、重命名后旧访问地址转发均通过。

参考：[阿里云 S3 接入说明](https://www.alibabacloud.com/help/zh/oss/developer-reference/use-aws-sdks-to-access-oss)。
