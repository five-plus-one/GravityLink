# 链接管理、统计与对象存储验收

## 交付功能

- 管理端、登录、初始化和公开页使用 SVG 链环标识；页脚跳转 https://r-l.ink/glink。
- 桌面收起侧栏宽64px，菜单图标居中；链接操作列固定在右侧，打开和编辑按钮位置统一。
- 链接用途区分短链、渠道、群活码、客服码、卡密提取。卡密入口使用对应配置，群活码可正常打开目标管理。
- 链接分类与标签可创建、编辑、筛选；支持最低访问量和访问量升降序。手机卡片展示分类、标签和访问量。
- 统计和访客记录的时间选择组件集成7个快捷时段。统计支持精确起止时间，小时图展示最近24小时连续区间。
- OIDC 请求用户名和邮箱，服务端验证身份令牌并同步资料。个人中心使用常规资料列表。
- 图片存储支持 S3 兼容服务与CDN域名，新上传返回CDN地址，已有本地素材可批量上传、重试；历史地址继续访问。
