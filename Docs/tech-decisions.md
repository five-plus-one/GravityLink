# 技术选型决策

## 已确认选型

| 层级 | 技术 | 理由 |
|-----|------|------|
| 后端语言 | Go 1.22+ | 原生高并发，goroutine 极低内存开销，适合短链接高并发重定向场景 |
| Web 框架 | Gin | 生态最成熟，new-api 同款，社区资源丰富，性能满足需求 |
| 前端框架 | Vue 3 + TypeScript | 组合式 API，类型安全，生态成熟 |
| 前端构建 | Vite | 管理端开发热更新快，生产可独立部署在受限管理域名下 |
| 主数据库 | MySQL 8.0+ | 兼容旧版数据，运维成本低，开源用户门槛最低 |
| 缓存 | Redis 7+ | 热路径缓存（短链映射）+ 统计预聚合 + 访问日志队列 |
| ORM | GORM | Go 生态最成熟的 ORM，支持自动迁移 |
| 身份认证 | Logto（自托管） | 用户已有现成部署，支持 OIDC 标准，Web UI 完善 |
| 权限模型 | RBAC 单租户 | Admin / User 两种角色，架构简单，后续可扩展多租户 |
| IP 归属 | ip2region | 离线数据库，无外部依赖，支持省市级查询 |
| UA 解析 | mssola/useragent | 轻量，解析设备/OS/浏览器 |
| 部署 | Docker + docker-compose | 一键拉起所有依赖，对开源用户友好 |

## 部署模式

- Go 后端承接公网短链访问：入口域名直接返回 302，落地域名服务端渲染页面。
- Go 使用 `//go:embed` 内嵌公网落地页 CSS/JS 和 Vue 管理端构建产物，生产只需要一个 GravityLink 应用容器。
- 应用容器默认暴露两个端口：`8080` 为后端 API/公网短链路由，`8081` 为管理端前端；管理端端口内的 `/api/*` 会转给同一个后端 handler。
- Vue 管理端用于后台运营，不作为公网用户入口；生产环境应部署在管理域名并通过 Nginx/IP 白名单/认证限制访问。
- 服务运行依赖 MySQL + Redis，并提供 docker-compose.yml 一键部署版本。

## 未引入的技术及原因

| 技术 | 未引入原因 |
|-----|-----------|
| ClickHouse | 额外运维成本，对开源用户不友好；MySQL + Redis 预聚合已满足需求 |
| Kafka | 流量规模暂不需要，Phase 1 使用 Redis List 已满足异步统计落盘；后续高可靠消费场景再评估 Redis Stream |
| Fiber | Fasthttp 与 net/http 生态不兼容，中间件生态弱于 Gin |
| 微服务 | 单体应用更易于部署和维护，用模块内路由隔离替代服务拆分 |
