# 查询与分发体验修复方案（2026-09-13）

## 现状与原因

- 访客日期使用 UTC 截断，导致本地日期偏移且丢失时分秒；首次加载重复发请求，查询没有竞态保护。分页虽有 remote，但需验证真实总数、稳定排序与筛选联动。
- 全部链接统计未调用设备和地域接口；单链接分布只读历史聚合，遗漏当天。小时图固定今天，与日期选择割裂。
- 卡密项目与落地页、领取链接之间缺少可操作引导；落地页要求填写不可见项目编号；卡密及领取记录分页未闭环，重复领取检查在事务外。
- 移动导航的脚本/CSS 断点不一致，主布局样式穿透所有嵌套滚动容器；链接表横向信息及动作过多。

## 实施范围

1. 访客查询联合实时记录与归档记录，归档兼容现有列集合；支持精确时间及快捷范围，保留本地时区；明确已应用筛选、加载/错误/空态；稳定分页并防止过期响应覆盖。
2. 新增全部链接设备/地域接口；历史分布叠加当天明细且避免重复；小时图响应所选日期范围，日期格式统一。
3. 卡密项目详情提供领取页/链接配置入口，落地页使用项目名称选择；补齐分页、导入去重、库存刷新与事务内重复领取检查。
4. 桌面链接表集中名称与访问地址，动作分组；移动端提供链接卡片与可触达导航，统一容器溢出与筛选换行。
5. Go 构建及测试、前端类型/单测/构建；重建现有本地 Docker 应用，保留数据卷与配置；用独立测试项目进行真实查询、分页、领取与响应式验收。

## 验收

- 指定时间、关键词、第二页与每页条数均产生正确结果，空结果可恢复。
- 今日设备/系统/浏览器及全部链接分布可见；统计与原始访问明细对应。
- 创建项目→导入→配置领取页→发布链接→访问领取→后台记录可完成；口令和重复提取规则有效。
- 390px、768px、1440px 页面主区域不横向溢出，菜单和常用操作可达。

本次按用户授权连续完成方案、修复和本地部署；不变更数据库结构，不修改环境文件。
