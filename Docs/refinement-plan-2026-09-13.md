# 链接管理与统计交互改进

## 实施方案

- 品牌统一使用简洁单色 SVG 链环，页脚保持小尺寸，访问地址使用 https://r-l.ink/glink。
- 侧栏折叠宽度与菜单内边距统一，操作列固定顺序及位置。卡密入口不提供二维码目标配置；按落地页区分群码、客服码、卡密提取。
- 链接支持类型与访问量筛选、排序；分类和标签使用独立持久字段，增量迁移待用户确认。
- 时间选择组件集成最近1小时、今天、最近24小时、本周、最近7天、本月、最近30天；统计精确时段使用访问明细，历史日期统计保留兼容。小时趋势按真实时间顺序展示最近24小时。
- OIDC 资料来自服务端验签的身份令牌，匹配访问令牌主体和客户端，更新用户名及邮件，保留本地角色和状态。
- 个人中心采用常规资料布局；各页面只保留操作所需说明。

## 验证

覆盖卡密与群码配置入口、时间边界和跨日小时序列、OIDC资料验证、分类筛选；执行 Go 与前端测试、Docker部署及浏览器桌面和移动端检查。

用户已授权分类与标签增量迁移。迁移程序随版本保留，使用版本表和数据库锁；启动先执行迁移，成功后记录版本，部分失败可重试。

OIDC参考：[Logto scopes 与 ID token claims](https://docs.logto.io/quick-starts/express)。请求 openid/profile/email，并验证身份令牌的签名、issuer、客户端audience、主体、有效期与azp；账户同步只更新用户名和邮件。
